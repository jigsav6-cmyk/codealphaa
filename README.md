# ✅ Task 1: Hangman Game

### Description
A console-based Hangman game where the player guesses a hidden word one letter at a time. The player has six chances to guess incorrectly before losing the game.

### Features
- Random word selection
- Maximum 6 wrong attempts
- User-friendly console interface
- Win/Loss detection

### Concepts Used
- Random Module
- Lists
- Strings
- Loops
- Conditional Statements

# ✅ Task 2: Stock Portfolio Tracker

### Description
A simple stock portfolio management system that calculates the total investment value based on user-entered stock quantities and predefined stock prices.

### Features

- Automatic investment calculation
- Portfolio summary generation
- File handling support

### Concepts Used
- Dictionaries
- Loops
- Arithmetic Operations
- File Handling
- User Input
